## Problem Statement (Labs 1 - 3)

**#04 — Student Project Portfolio & Showcase App**

Annual project expos need a centralized showcase where student teams submit multimedia artifacts, judges grade projects using digital rubrics, and the public votes with strict anti-sybil protections.

**Actors:** Student Team, Panel Judge, Public Voter

## Repo Structure

- `/lab_1/` — Requirements Engineering & UML Use-Case Modelling (requirements table, use-case diagram, use-case flow spec)
- `/lab_2/` — Agile Backlog Creation & Sprint Simulation in Jira (backlog/epics, story points, sprint board, burndown chart, reflection doc)
- `/lab_3/` — Software Architecture Design (component diagram and architecture justification)
- `/lab_4/` — Vibe Coding (before/after demo videos of the LLM-assisted changes, and links to the LLM chat and forked repo)
- `/lab_5/` — Static Code Analysis & Code Quality (Pylint, Flake8 and Bandit reports before and after fixes, issues log, link to forked repo)
- `/lab_6/` — Code & Branch Coverage Testing (test suites for line and branch coverage with coverage screenshots, link to forked repo)
- `/lab_7/` — Fuzz Testing (test cases for the processor module, fuzz testing report, link to forked repo)

Labs 1 to 3 are based on the problem statement above; Labs 4 to 7 use separate applications. Each folder contains that lab's deliverables as submitted.
